# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability or potential disclosure risk (including unintentional inclusion of PHI or real patient data), please **do not open a public GitHub issue**.

Instead, report it privately to the repository maintainers:
- **Kailash Reddy**: kailash@datakaveri.org
- Or via GitHub Private Vulnerability Reporting on this repository.

We will acknowledge receipt within 48 hours and work on patching high-severity issues within 7 days.
